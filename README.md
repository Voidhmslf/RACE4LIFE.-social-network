# Race4Life

Учебный блог об автоспорте: Формула-1, инженерия, история трасс и симрейсинг. Сделан в рамках курса по блоггингу — 465 материалов за 31 день (16 сентября — 16 октября 2026), по 15 в день.

Это статический сайт без сервера: всё работает в браузере, данные лежат в `localStorage`.

## Что умеет

- лента с сортировкой, живой поиск по заголовкам и тексту;
- четыре рубрики: Формула-1, Авто-Научпоп, История треков, Симрейсинг;
- архив по дням (календарь) с фильтром по дате;
- режим чтения и режим редактора: создание, правка и удаление материалов;
- лайки и счётчик просмотров (значения на старте сгенерированы, это демо-данные);
- экспорт базы в JSON и сброс к исходным 465 материалам.

Это не соцсеть: нет аккаунтов, комментариев и общей базы — данные видны только в вашем браузере.

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python -m http.server 8000
```

Tailwind и иконки подгружаются с CDN, поэтому для первого открытия нужен интернет.

## Структура

```
index.html            разметка
styles.css            оформление поверх Tailwind
app.js                логика интерфейса: лента, календарь, поиск, редактор
data-generator.js     начальная база: порядок тем, даты, обложки, просмотры
articles.js           тексты статей (собирается из content/, руками не править)
content/              исходники текстов: по 2–3 темы на файл
images/               обложки
tools/
  build_articles.js     node tools/build_articles.js — собрать articles.js
  validate_articles.js  node tools/validate_articles.js — проверить полноту и дубли
  legacy/               старый Python-конвейер коротких заготовок (не используется)
```

## Как править тексты

1. Измените нужный файл в `content/`. Разметка: абзацы через пустую строку, `### Заголовок`, `> цитата`, списки через `- ` и `1. `, `**жирный**`.
2. `node tools/build_articles.js` — пересобрать `articles.js`.
3. `node tools/validate_articles.js` — проверить, что нет пропусков, коротких текстов и повторов.
4. Если менялись тексты, увеличьте версию ключа хранилища в `data-generator.js` (`race4life_posts_vN`), иначе браузер покажет старую базу. Либо нажмите «Сбросить» в интерфейсе.
